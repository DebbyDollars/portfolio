## 🚀 Getting Started

### Prerequisites
- A GitHub account
- Basic knowledge of HTML/CSS/JS (for customization)

### Installation

1. **Clone or download this repository**

```bash
git clone https://github.com/DebbyDollars/portfolio.git
cd portfolio
Add your assets

Replace assets/gbemi.jpg with your own photo

Replace all work sample images in assets/ with your own project screenshots

Add assets/og-image.jpg (1200×630px) for social previews

Add favicon files (use a favicon generator)

Replace assets/Gbemi_Resume.pdf with your actual resume

Customize content

Update text in index.html (hero, about, services, testimonials)

Update contact links (email, WhatsApp, calendar)

Update social media links

Deploy to GitHub Pages

bash
git add .
git commit -m "Initial portfolio deployment"
git push origin main
Then go to Settings → Pages → Select main branch → Save.

🎨 Customization Guide
Change Typewriter Phrases
Edit the phrases array in script.js:

javascript
const phrases = [
    'Operational Excellence',
    'Administrative Systems',
    'Strategic Support',
    'Scalable Operations',
    'Founder\'s Ally',
    'Efficient Workflows'
];
Update Brand Colors
Edit the CSS variables in :root:

css
:root {
    --terracotta: #C97B63;      /* Primary color */
    --sage: #8FAD9A;            /* Secondary color */
    --cream: #FDF7F2;           /* Background color */
}
Change the Blob Colors
Edit the SVG gradient in index.html:

html
<stop offset="0%" stop-color="#C97B63" stop-opacity="0.25" />
<stop offset="100%" stop-color="#8FAD9A" stop-opacity="0.05" />
Adjust Carousel Speeds
In script.js:

javascript
// Work carousel (currently 5s)
const workAutoDelay = 5000;

// Testimonial carousel (currently 3.5s)
const autoSlideDelay = 3500;
